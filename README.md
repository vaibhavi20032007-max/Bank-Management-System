# Bank Management System

## Project Description

The Bank Management System is a console-based Java application developed using Object-Oriented Programming concepts. It allows users to create bank accounts, deposit money, withdraw money, and view account details.

## Technologies Used

- Java 27
- Java Collections Framework
- Object-Oriented Programming
- Exception Handling
- Command Line Interface

## Features

- Create a new bank account
- Support multiple accounts
- Deposit money
- Withdraw money
- Check account details and balance
- Search account using account number
- Prevent duplicate account numbers
- Validate input
- Handle invalid transactions using exception handling
